# fiap-pos-tech-ai-scientist-fase-1-desafio
## Desafio Tech da fase 1 da pós-tech em AI Scientist pela FIAP.

#### Objetivo do Projeto
O presente trabalho tem o propósito de fazer uma análise sobre o NPS e sua relação com as demais variáveis operacionais da base de dados operacional de um e-commerce, além de buscar insights sobre os próximos passos para que se corrijam os problemas que serão identificados na observação.

#### Descrição da Base de Dados
A base de dados apresenta variáveis de idade do cliente, região geográfica do cliente tempo de relacionamento do cliente com a empresa, valor total do pedido, quantidade de itens no pedido, valor de desconto aplicado ao pedido, número de parcelas do pagamento, tempo total de entrega, quantidade de dias de atraso na entrega, valor do frete, número de tentativas de entrega, número de contatos do cliente com o atendimento, tempo para resolução de problemas, número de reclamações registradas pelo cliente, indicação se houve recompra em até 30 dias após o pedido, CSAT (Score Interno de Satisfação do Cliente), e NPS (Nota de satisfação do cliente.

#### Metodologia Utilizada
Foram analisados fatores como a distribuição de notas do NPS, medidas estatísticas descritivas, o percentual das categorias de NPS para o e-commerce e uma matriz de correlação entre o NPS e as demais variáveis da base de dados.
